# Mice-Resistance-Fitting-APP

这是论文 **** 的官方配套 MATLAB 软件与实现代码。

本工程基于 **MATLAB R2021b** 开发，提供了一个直观的图形用户界面（GUI），用于实现论文中所提出小鼠各组织器官阻抗拟合算法。

---

## 核心功能
  该数学模型基于经典的生物阻抗 Cole-Cole 模型，用于描述不同月龄下器官的电生理特性。公式中的 |Z|代表阻抗模值，ω为角频率；
核心参数中，R_1通常对应无限高频下的外液电阻，R_2为与细胞内液相关的等效电阻，Q是反映组织伪电容特性的常相位角元件（CPE）参数，而α则为表征组织不均匀度与非理想电容效应的弥散系数（介于 0 到 1 之间）。
  为了引入时间维度以动态评估器官的发育进程，模型创新性地采用线性展开的方式，假定这四个核心阻抗参数均随月龄month呈线性变化——其中下标为A的系数（如 R1_A等）代表各电学特性随月龄增长的演变速率（斜率），下标为B的系数（如R1_B等）则代表初始状态的基础基准值（截距），从而能够通过一组定量的拟合参数完美捕捉生物组织随生长发育的阻抗演变规律。

## 🚀 快速开始

根据您的设备环境，选择以下三种方式之一运行或安装：

### 选项 A：在 MATLAB 中直接运行源码
1. 下载或克隆本仓库到本地：
2. 打开 MATLAB R2021b，将当前工作目录切换至本项目根目录。
3. 在 MATLAB 命令行窗口中直接输入MICE.mlapp文件并回车运行。或者在 MATLAB 文件浏览器中直接双击 MICE.mlapp 运行。
4. 
### 选项 C：在无 MATLAB 环境的电脑上运行（推荐普通用户）
进入本仓库的 release/ 文件夹。
下载MyAppInstaller_web.exe 独立运行程序。
双击运行安装程序。安装过程中，程序会自动提示并免费下载安装对应版本的 MATLAB Runtime。安装完成后双击桌面快捷方式独立运行。
